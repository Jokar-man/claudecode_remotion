# Onthology Demo — CapCut Assembly Guide

**Total runtime:** ~80–85 seconds · **Resolution:** 1280×720  
**Music:** Subtle ambient/electronic (CapCut Audio → search "ambient technology")

All clips show the **full application UI** (map + chat panel) at native 16:9 ratio. Each clip has a subtle dark vignette and a thin orange accent line at the bottom for visual consistency.

---

## Text Card Styling (apply to ALL text cards)

- **Background:** black
- **Font:** Montserrat Bold (or Inter / Helvetica)
- **Main text:** white, centered
- **Stat numbers:** orange #FF8C00
- **Animation In:** CapCut → Text → Animation → In → **Typewriter**
- **Animation Out:** Fade (0.3s)

## Transitions

- **Text card → Video clip:** Fade transition (0.3s)
- **Video clip → Text card:** Fade transition (0.3s)
- **Video clip → Video clip** (consecutive map clips like 03→04, 07→08): **Hard cut, no transition.** The map zoom provides natural continuity.

---

## Optional Design Touches

- **Step counter:** Add a small `01` / `02` / `03` text in bottom-left of each video clip (14pt, orange, 40% opacity)
- **Music dynamics:** 30% volume on trailer, 15% during video clips, 25% during text cards, fade out on end card
- **Slow zoom on text cards:** CapCut → select text card → Basic → Scale from 100% to 102% over the duration. Adds subtle life.
